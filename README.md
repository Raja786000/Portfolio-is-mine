# Raja Babu — Modern Portfolio

A responsive, modernized version of the original portfolio using Next.js, React and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Main files

- `app/page.js` — portfolio content and interactions
- `app/globals.css` — complete responsive visual system and animations
- `public/assets/RajaResumeDS.pdf` — original resume
